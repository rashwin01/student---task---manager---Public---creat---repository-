# Student Task Manager

A small web application created as a GitHub learning project.

## Project Objective
The Student Task Manager helps university students record assignments and other academic tasks, set due dates and priorities, and mark tasks as completed.

## Requirements
- Add a task title
- Select a due date
- Select task priority
- Display saved tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Store tasks in browser local storage

## User Role
**Student:** Can add, view, complete and delete academic tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Add tasks using the form.

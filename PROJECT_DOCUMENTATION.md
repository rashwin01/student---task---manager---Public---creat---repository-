# Student Task Manager - Project Documentation

## 1. Introduction
Student Task Manager is a small web-based application designed to help university students manage academic assignments and deadlines.

## 2. Problem
Students may forget assignment deadlines or have difficulty organizing several academic tasks.

## 3. Proposed Solution
The application provides a simple interface where a student can add tasks, set due dates and priorities, mark completed tasks, and delete tasks.

## 4. Functional Requirements
1. The system shall allow a student to add a new task.
2. The system shall allow the student to enter a due date.
3. The system shall allow the student to select High, Medium or Low priority.
4. The system shall display all tasks.
5. The system shall allow the student to mark a task as completed.
6. The system shall allow the student to delete a task.
7. The system shall store tasks using browser Local Storage.

## 5. User Role
### Student
- Add academic tasks
- View tasks
- Complete tasks
- Delete tasks
- Remove completed tasks

## 6. Software Features
- Responsive user interface
- Task creation form
- Due-date management
- Priority selection
- Complete/Undo function
- Delete function
- Local data storage

## 7. Technologies
- HTML5 for structure
- CSS3 for design
- JavaScript for application logic
- Local Storage for saving task data
- GitHub for source-code hosting and version control
